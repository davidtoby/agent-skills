# Style Variants

This skill supports multiple visual directions from the same underlying report content.

## 1. Consulting / Executive Summary

Use when the user wants a polished, premium, general-purpose business summary.

Characteristics:
- blue-gray palette
- restrained visual accents
- clear section hierarchy
- concise cards or blocks
- suitable for broad internal sharing

## 2. McKinsey-style

Use when the user wants something closer to a board brief or management memo.

Characteristics:
- colder, more austere palette
- stronger whitespace discipline
- fewer decorative containers
- more formal tone
- better for executive readers

## 3. BCG-style

Use when the user wants a more modern strategy-report feel.

Characteristics:
- clean grid
- slightly more modern energy
- restrained teal/green allowed
- still analytical, not playful

## 4. Apple-inspired personal brand

Use when the user wants founder-brand or creator-brand output.

Characteristics:
- lighter, airier composition
- Apple-like blue plus muted neutral grays
- subtle gradients only
- personal/company attribution on cover and footer
- softer, more elegant presentation than consulting-firm variants

## Decision rule

If the user does not specify a style:
- default to consulting / executive summary

If the user asks for a very formal leadership audience:
- prefer McKinsey-style

If the user asks for a more contemporary strategy feel:
- prefer BCG-style

If the user wants personal branding or founder branding:
- prefer Apple-inspired personal brand
