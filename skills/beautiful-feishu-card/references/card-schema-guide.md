# Schema 2.0 组件与布局结构参考

本参考文档提供飞书互动卡片 Schema 2.0 验证通过的核心 UI 组件 JSON 结构片段与组装示例。

---

## 1. 基础结构 (Base Skeleton)

```json
{
  "schema": "2.0",
  "header": {
    "title": {
      "tag": "plain_text",
      "content": "📌 标题名称"
    },
    "subtitle": {
      "tag": "plain_text",
      "content": "副标题或时间日期"
    },
    "template": "blue"
  },
  "body": {
    "direction": "vertical",
    "elements": []
  }
}
```

---

## 2. 核心 UI 组件片段

### (1) 分割线 (`hr`)
用于逻辑区域解耦，极大提升卡片透气感与美观度：
```json
{
  "tag": "hr"
}
```

### (2) 文本块与 Markdown 格式 (`div` with `lark_md`)
支持标题级别 (`#####`), 加粗 (`**text**`), 代码风格 (`` `code` ``), 以及文字着色：
```json
{
  "tag": "div",
  "text": {
    "tag": "lark_md",
    "content": "##### 1. 概述与目的\n**项目背景**：本次更新旨在修复核心网络与系统的兼容性问题。\n- 指标一：<font color='green'>**已升级 (99.8%)**</font>\n- 指标二：<font color='red'>**异常待跟进 (2 个)**</font>"
  }
}
```

### (3) 分栏数据块 (`column_set`)
用于展示对称数据、对比指标、或侧边属性，是呈现丰富数据信息的关键组件：
```json
{
  "tag": "column_set",
  "flex_mode": "none",
  "background_style": "default",
  "columns": [
    {
      "tag": "column",
      "width": "weighted",
      "weight": 1,
      "elements": [
        {
          "tag": "div",
          "text": {
            "tag": "lark_md",
            "content": "**负责人**\n张三 (Networking Team)"
          }
        }
      ]
    },
    {
      "tag": "column",
      "width": "weighted",
      "weight": 1,
      "elements": [
        {
          "tag": "div",
          "text": {
            "tag": "lark_md",
            "content": "**状态**\n<font color='orange'>**处理中 (In Progress)**</font>"
          }
        }
      ]
    }
  ]
}
```

### (4) 状态 Label 徽章 (Status Badges in `lark_md`)
Schema 2.0 中使用 `<font color='...'>` 拼接方括号 Markdown 形成现代感 Badge：
```json
{
  "tag": "div",
  "text": {
    "tag": "lark_md",
    "content": "<font color='green'>**[ 成功: 2/6 台 ]**</font>  <font color='red'>**[ 失败: 4/6 台 ]**</font>  <font color='orange'>**[ 高优先: F13 ]**</font>"
  }
}
```

### (5) 底部辅助说明 (Footer in `lark_md`)
Schema 2.0 推荐使用灰色小字作为 Card Footer：
```json
{
  "tag": "div",
  "text": {
    "tag": "lark_md",
    "content": "<font color='grey'>💡 Generated by Beautiful Feishu Card Skill</font>"
  }
}
```

## 3. CardKit 包裹契约 (.card File Contract)

在保存落盘 `.card` 文件时，必须包裹在 CardKit 数据结构中：

```json
{
  "name": "卡片名称示例",
  "dsl": {
    "schema": "2.0",
    "header": {
      "title": { "tag": "plain_text", "content": "示例标题" },
      "template": "blue"
    },
    "body": {
      "elements": [
        {
          "tag": "div",
          "text": { "tag": "lark_md", "content": "卡片正文" }
        }
      ]
    }
  },
  "variables": []
}
```
