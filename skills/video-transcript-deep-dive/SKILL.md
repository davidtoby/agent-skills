# Video Transcript Deep Dive (视频逐字稿深度提炼与双语洞察)

将长篇音视频逐字稿（学术公开课、思想对谈、社会纪实纪录片、深度播客、系列讲座播放列表等）提炼重构为**出版级双语长篇思想论著、系统化图解模型、现象学/社会学隐喻矩阵与观点鲜明的批判洞察**，并自动沉淀至用户的知识库体系（如 Obsidian）。

本技能支持**单视频深入剖析**与**播放列表（Playlist）全量自动化批量处理**。

---

## 核心价值与定位

普通 AI 总结的通病是**“清单化、干瘪化、中庸化”**——将原本充满生命力与张力的思想撕裂为干瘪的要点列表，抹平了所有的反思锋芒。

本 Skill 确立了全新的交付标准：
1. **拒绝干瘪摘要，交付出版级长文**：将口语化的逐字稿重塑为兼具思想深度与修辞力量的长篇结构化文章（中文版与英文版各占完整篇幅，保持相同学术与文学深度）。
2. **可视化认知与叙事模型**：提炼演化阶段图、认知反馈环或戏剧冲突架构，提供 ASCII 或 Mermaid 图谱。
3. **现象学与社会学隐喻矩阵**：挖掘文本中超越表象的深层隐喻（如“65,000条交叉引用”、“3000元代际断裂”、“砸碎水晶宫”）。
4. **拒绝正确的废话，亮出鲜明锋芒**：在文末提供 4-5 条直击本质、具有强烈哲学/社会学批判维度的独立洞察，敢于挑战主流共识与主讲人的潜在盲区。
5. **知识库原生沉淀与系列联动**：自动适配 Obsidian 等 Markdown 知识库的双链引用与排版规范，针对播放列表自动构建上一集/下一集/总览导航。

## 步骤详解与实操指南

### 步骤 1：字幕获取与预处理

#### A. YouTube 单视频免下载提取（规避 429 封禁）
当使用 `yt-dlp` 下载 YouTube 字幕时，默认客户端频繁触发 `HTTP Error 429: Too Many Requests`。  
**必须指定 `android` 客户端**，以轻量化且稳定的方式提取字幕：

```bash
# 仅下载字幕（不下载视频音频），使用 android 客户端规避风控
python scripts/fetch_youtube_subtitles.py "https://www.youtube.com/watch?v=VIDEO_ID" -o ~/Downloads
```

底层直接执行：
```bash
yt-dlp \
  --extractor-args "youtube:player_client=android" \
  --skip-download \
  --write-auto-sub \
  --sub-lang "en-orig,en.*,zh.*" \
  --sub-format srt \
  -o "~/Downloads/%(title)s.%(ext)s" \
  "YOUTUBE_URL"
```

#### B. 逐字稿清洗与去重（Python）
YouTube 自动字幕通常包含大量的**重复单字与重叠行**，必须进行流式去重与分段：

```bash
# 单文件清洗
python scripts/clean_srt.py "/path/to/source.srt" --chunk-minutes 10 -o "/path/to/cleaned.txt"

# 目录批量清洗（处理播放列表所有字幕）
python scripts/clean_srt.py "/path/to/subtitles_folder" --chunk-minutes 10
```

## 播放列表（Playlist）批量处理工作流与实战标准

当用户输入一个包含多个视频的播放列表 URL（如 `https://www.youtube.com/playlist?list=...` 或带 `&list=` 的视频 URL）时，执行以下标准化流程：

### 1. 播放列表解析与预检 (Inspection & Discovery)
调用 `fetch_youtube_subtitles.py` 进行元数据探查：
```bash
# 仅预检条目清单，不开始下载
python scripts/fetch_youtube_subtitles.py "PLAYLIST_URL" --list-only
```
- **自动识别与过滤**：通过 `--flat-playlist -J` 解析播放列表清单，自动标记并排除 `[Private video]`（私享视频）、`[Deleted video]`（已删除视频）及失效占位符。
- **输出清晰条目报告**：向用户呈报原播放列表总数、可用视频数、被隐藏/失效视频数。

### 2. 免视频批量安全下载 (Batch Subtitle Extraction)
执行批量下载指令：
```bash
python scripts/fetch_youtube_subtitles.py "PLAYLIST_URL" -o ~/Downloads/Playlists
```
- 脚本自动创建以播放列表名称命名的子目录；
- 文件名自动追加原始播放顺序前缀（如 `[01] 标题.en-orig.srt`, `[02] 标题.en-orig.srt`）；
- 针对每一项均通过 `android` client 直取字幕，全程**零视频/音频下载**，极速且节省流量。

### 3. 目录级批量去重清洗
```bash
python scripts/clean_srt.py ~/Downloads/Playlists/<播放列表名>
```
脚本会按顺序为每个字幕生成 `.cleaned.txt`，去除叠词与时间轴冗余，标注每 10 分钟时间节点。

### 4. 串行出版级重构与系列双链沉淀
- 对可用视频按序推进深度处理，绝不因批量而降低单篇质量；
- **命名规范**：
  `【<系列名称>】<序号>. <核心主题>：<讲者>《<原题>》中英长文与深度洞察.md`
- **系列双链联动**：在每篇文章顶部添加：
  `[[上一篇]] | [[【系列总览】系列名称导航]] | [[下一篇]]`
- **生成系列总览索引**：汇编整季/全列表核心主题矩阵、整体思维脉络总图（Mermaid）及全套文章导航。

## 步骤 2：内容分析与架构提炼

在动笔之前，必须对清洗后的文本进行三层穿透分析：
1. **经验层（What happened）**：人物的事实轨迹、核心论据、引用文献（先哲、历史事件、社会调查）。
2. **认知/现象学层（How it functions）**：行为背后的心理动力学模型（如：为什么人会主动砸碎水晶宫？为什么道德始于行动而非条文？）。
3. **时代/社会学层（Why it matters now）**：该文本在当下的制度困境、技术狂潮（AI时代、算法异化）中具有何种警示意义。

## 步骤 3：六位一体文档产出标准

撰写文档时，严格遵循以下结构（详细模板见 `references/output-structure.md`）：

1. **档案与元数据**：以清晰表格列出原题、所属系列、时长、主讲人、交叉学科、核心对话典籍。
2. **执行摘要（Executive Summary）**：500字内提炼全文最核心的 4-5 个破局逻辑。
3. **核心图解**：用 ASCII 或 Mermaid 绘制思维模型（如演化三阶图、自毁闭环图、二元张力模型）。
4. **中文深度长文**：
   - 杜绝口语化流水账，写成结构严密、文风凝练的学术/深度纪实论著；
   - 设引言、正文（4-5个具有思想深度的分章小标题）、结语；
   - 完整还原文本中的经典论据、哲学辩驳与心理学案例。
5. **英文深度长文（Comprehensive English Article）**：
   - 采用专业英文学术散文与非虚构叙事风格；
   - 保留精准的术语对应（如 *Imago Dei*, *The Logos*, *Pathological Adventure*, *Teleological Perception*）；
   - 论述力度与中文版完全对等，绝非简陋翻译。
6. **核心概念与隐喻解析矩阵**：
   - 表格形式，对比“浅层字面理解”与“深度心理学/社会学演化阐释”。
7. **独立总结与鲜明批判洞察（核心亮点）**：
   - **核心总结**：提炼文本的哲学/社会学公理；
   - **鲜明洞察（Critical Insights）**：提供 4-5 条极具思想锐度的批判性剖析：
     - *反思常识*：击碎流行文化的浅薄教条（如揭露新无神论的幼稚病、戳破程序员中产神话）；
     - *质疑讲者*：指出主讲人本身的哲学盲区、实用主义陷阱或历史浪漫化偏见；
     - *时代关照*：连接当下现实（如 AI 算法异化、家庭债务断裂、数字极简地狱）。

## 质量控制红线（Do's & Don'ts）

- **Do**：深入到人类演化、深度心理学与社会结构的底层逻辑，挖掘言语背后的潜意识驱动力。
- **Do**：保持中文与英文两篇长文的同等学术分量与文学品质。
- **Do**：文末洞察必须**观点鲜明、有棱有角**，敢于做出价值判断与哲学批判。
- **Do**：遇到播放列表时，先检查可用性并过滤私享失效视频，输出结构化清单后再批量执行。
- **Don't**：禁止产出“第一点、第二点、第三点”的干瘪要点列表；长文必须是具备上下文论述与文采的完整思想论著。
- **Don't**：下载 YouTube 视频本身；仅提取字幕，最大化节省磁盘与带宽。
- **Don't**：在文末写“以上观点各有道理”式的和稀泥废话；洞察必须具有锋芒与智识冲击力。
